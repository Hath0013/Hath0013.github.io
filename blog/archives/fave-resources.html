Favourite design resources 🎨

Last updated: Feb 25, 2026

Sharing is caring. Here are some of the MOST valuable resources I've discovered on my design journey. I'll continually update this list, so do check back every once in a while!

Accessibility

  • Color contrast checker: Easy way to ensure your text is WCAG compliant.
  • Eightshapes contrast grid: Best way to test many hex codes for WCAG 2.0 min contrast.
  • WebAIM contrast checker: An alternative colour contrast checker tool.

Colour

  • Color Blender: Blend one hex to another.
  • ColorPal: Chrome/Edge extension for easy browser hex-picking.
  • ColorSpace: Spits out a bunch of palettes from a single hex.
  • Shade Generator: Throws shade.
  • Tint & Shade Generator: When you need quick tints of a hex code.

CSS

  • cssfontstack: A complete collection of web safe CSS font stacks.
  • css.glass: Create a CSS glass effect.
  • CSS Generators: I love generators for visualizing before coding, saves so much time.
  • CSS Reference: Extensive CSS reference with all the important properties and info to learn CSS from the basics, no to mention it has a simple and sexy colour-coded layout.
  • nekoCalc: PX to REM converter.
  • spinkit: Ready to use CSS spinners.

Design Systems

  • Carbon Design System: IBM's design system.
  • Material Design: Google's design system.
  • Spectrum: Adobe's design system.

Icons

  • Font Awesome Icons V4: A library of all the completely free and available Font Awesome Icons.
  • heroicons: Beautiful hand-crafted SVG icons, by the makers of Tailwind CSS.
  • pixelarticons: My 8-bit heart couldn't resist throwing this one in.

Imagery

  • GoFullPage: Chrome extension for full page screen capture with customizable settings.
  • nekoCalc: Generate custom SVG & PNG visual assets.
  • Ruler Measurement: Easy, quick pixel dimensions for digital components.

Typography & Fonts

  • WhatFont: Chrome extension for the easiest way to identify fonts on web pages.

Creative Stimulation & Learning

  • Creative Boom: Based in the UK. They also have a great podcast!
  • Nielsen Norman Group: Incredible library of UX & UI content.
